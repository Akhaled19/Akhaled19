# 👋 Hi, I'm Azal!

🎓 Senior Computer Science student at UMass Boston (GPA: 3.9/ 4.0)

🤖 Applied AI & Machine Learning | Software Engineering

**How can we turn data into better decisions and AI into practical tools that make a real impact?**<br>
That's the question that drives me to keep learning, building, and exploring new technologies.

I'm passionate about developing intelligent systems by combining machine learning, large language models, and software engineering. Through the **Break Through Tech AI Fellowship**, I've built a strong foundation in both machine learning and applied AI by working through the complete development lifecycle—from cleaning and preparing raw data to training, evaluating, and deploying models.

My projects have included:

* 📊 Predictive modeling using Logistic Regression and Neural Networks
* 👁️ Computer Vision for image classification
* 📝 Natural Language Processing (NLP) for text extraction and analysis
* 🔍 Retrieval-Augmented Generation (RAG) applications using LangChain, Chroma, and OpenAI
* 🤖 AI-powered applications using prompt engineering and agentic AI workflows

I'm particularly interested in applying AI and machine learning to solve complex, data-driven problems in industries like finance, while remaining excited about opportunities across many domains. One part of the ML workflow I especially enjoy is transforming messy, real-world data into reliable datasets that power meaningful models.

This GitHub is where I document my learning journey, showcase projects, and continue growing as an engineer.
